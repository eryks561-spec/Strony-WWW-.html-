Projekt: Strony WWW

Opis:
Ten projekt zawiera prostą stronę HTML z listą odnośników do popularnych serwisów internetowych.
Strona została wykonana ręcznie i ma na celu ułatwienie szybkiego dostępu do wyszukiwarek,
sklepów internetowych, marketplace, porównywarek cen, serwisów informacyjnych oraz innych
przydatnych stron.

Pliki:
- strony www.html – główny plik strony
- style.css – arkusz stylów (opcjonalnie, jeśli używany)

Zawartość strony:
Strona zawiera linki do:
- wyszukiwarek (Google, Bing, Yahoo, DuckDuckGo, Brave)
- sklepów z elektroniką (RTV EURO AGD, Media Markt, Komputronik, X-Kom, Morele, Neonet, Media Expert)
- marketplace (Allegro, Allegro Lokalnie, Amazon, Erli)
- porównywarek cen (Ceneo, Skąpiec)
- ogłoszeń lokalnych (OLX, Vinted)
- serwisów zakupowych (Temu, Aliexpress)
- księgarni internetowych (Empik, Świat Książki, Tania Książka, Bonito, Tezeusz)
- narzędzi do organizacji (Todoist, Notion)
- narzędzi do prezentacji (Canva, Google Slides, PowerPoint Online, Prezi, Visme)
- edytorów dokumentów (Word Online, Google Docs)
- drogerii (Rossmann, Hebe, Super-Pharm, Drogeria Natura, Notino, Sephora)
- dyskontów (Biedronka, Aldi, Carrefour, Auchan, Intermarché, E.Leclerc, Kaufland, Makro, Action, Lidl)
- serwisów informacyjnych (Onet, Interia, WP, Gazeta.pl, Wyborcza, MSN, Nowiny24)
- archiwów internetu (OldWeb.today, Web Design Museum, Internet Archive)
- innych stron (Gov.pl, Wikipedia, GitHub, BetaWiki)

Cel projektu:
Projekt ma charakter edukacyjny i demonstracyjny. Pokazuje podstawową strukturę strony HTML
oraz sposób tworzenia list odnośników.
